01 / Experimente

Teste uma entrega

Cada teste cria um evento fictício e faz uma tentativa de envio a um receptor controlado deste projeto.

{
  "event_type": "{{ demo.event_type }}",
  "payload": { "pedido_id": {{ demo.payload.pedido_id }} }
}
{% csrf_token %}

No sucesso, o receptor responde HTTP 200. Na falha controlada, responde HTTP 500. Os dois resultados devem ser registrados.
